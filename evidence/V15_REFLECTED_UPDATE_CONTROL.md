# Reflected neural update control

The 0.03 fresh-optimizer update failed on both consumed development starts. A deterministic policy pack was built by reflecting each of the 1,632 permitted network weight changes around the baseline weights, preserving all other actor weights, biases, observation normalization and semantic contracts. On the same retained observations, per-action correlations of original versus reflected joint-target changes ranged from -0.83 to -0.34. The network is nonlinear, so weight reflection is not an exact action reversal; this is a bounded exploratory control, not a policy-gradient proof. The initial pack creation failed before writing a pack because the script counted activation layers; that failure and the corrected version are retained.

On seed 20370113 the reflected policy fell at absolute step 239 (4.78 s) versus baseline 257 (5.14 s). On seed 20370127 neither fell in 250 resumed steps, but reflected peak tilt was 0.387 rad versus 0.129 rad baseline and exceeded the strict 0.35 rad balance threshold. It is rejected. These are reconstructed branch, forced-phase, scripted-carrier development tests, not an autonomous landing. Commands, pack, input hashes and full traces are archived.
