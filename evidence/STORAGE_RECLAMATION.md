# Verified cleanup on macmini

After the challenge/disturbance artifacts were pushed, a separately fetched bare repository reconstructed both split tarballs, matched their recorded aggregate SHA-256 values, and read/hash-checked every archived data file against the local run copies. The 42 files on macmini matched the retained SHA-256 manifest. Immediately before removal, the cleanup script rechecked each remote file hash and exact file set, rejected symlinks, and verified no open handles. Only the six completed raw run directories represented by those archives were removed; ongoing training, source inputs and the video copy were retained. Available space reported by `df -k` rose from 13,320,228 to 13,558,736 KiB (238,508 KiB). The archive also contains six locally derived first-episode analysis files.

After all eight v4 checkpoint archives were independently fetched from Git and every archive member was hash-checked against its remote file manifest, seven older updates' four redundant build files each (28 files) were re-hashed and checked for open handles, then removed from macmini. Update 08 and all ongoing inputs remained. `df -k` available rose from 12,980,476 to 13,139,224 KiB (158,748 KiB). The exact remote paths and checks are retained in v4-redundant-build-files-sha256.json and retire_v4_redundant_build_files.py.
