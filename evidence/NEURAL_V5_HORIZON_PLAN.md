# V5 longer-horizon balance experiment

The v3 challenge episodes develop gradual tipping that exceeds the .35-radian gate at intervals 519 and 486 and terminates at 596 and 563. The v4 training run covers only 512 intervals from reconstructed episode tick 2400, and the default 3000-tick timeout ends longer attempts around interval 600. Consequently 512-step rollouts cannot contain these particular terminal events from the first start. This observation motivates a prospective separate experiment; it does not establish that training horizon is the sole cause of failure.

After the preregistered v4 finishes, continue from its update-08 policy and optimizer using the same reward, action bounds, fixed learning rate, gamma .99, lambda .995, four environments and signed push curriculum. Raise the timeout to at least tick 5000 without changing physical-failure termination, and collect eight 768-step updates on new training seeds 20270411–20270418. Retain all raw rollouts, policies, optimizer states, logs and shader hashes. Evaluate v4 and v5 independently on the same four consumed starts using the existing no-push 1000-step physical fixture and strict first-episode terminal 250-interval gate. Report ties and regressions. This is not a held-out test, biological validation, or an autonomous mission.
