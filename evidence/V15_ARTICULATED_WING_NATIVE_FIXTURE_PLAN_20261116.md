# Articulated wing native fixture admission

Question: can the existing native v15 rollout instantiate and advance the new 41-body, 46-velocity-coordinate wing mechanics fixture without inventing air forces? The fixture retains the reconstructed v15 leg and toe chain, adds three revolute coordinates per wing, and intentionally has no aerodynamic program. The experiment is an engineering smoke test, not a flight, folding, control, contact-realism or biological qualification.

Build a dedicated adapter library and a copied rollout executable with an explicitly changed library dependency; preserve the existing library and executable. Use the existing journey and shader from the development configuration, no checkpoint or policy, one environment, 10 control steps, 16 physics substeps, and seed 20370113. Accept only successful model compilation and ten finite q, v and body states with no solver failure; record done/termination independently. The old task/shader was not designed for this topology, so rejection or a crash is a meaningful failure, not a license to relabel the result. Save commands, environment, source and binary hashes, stdout/stderr, state traces and full result. Do not reuse this fixture for flight or a trained policy.
