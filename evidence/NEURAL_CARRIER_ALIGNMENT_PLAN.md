# Matched perching carrier alignment experiment

The v4 stochastic training shader and deterministic evaluation differ in terminal perching: evaluation alone enables two contact-conditioned leg behaviors, populates foot-load feedback and advances the grip/release sequence. Training can also use a privileged command where evaluation cannot. These are code-level differences; their causal contribution remains unmeasured. Compare the original v4 training shader to a new shader with only these terminal-phase conditions aligned to evaluation while keeping training action sampling, likelihood calculation, reward, reset, random seeds, physical contact termination and signed pushes unchanged. The terminal privileged command is disabled only for episode band 10 with navigation stage at least five. The evaluation-only conditions are widened only for that same perching band and existing terminal conditions. No altered evaluation result is eligible for promotion.

Run four matched stochastic lanes for 512 intervals at already-used seed 20270511 with the same v3 actor/critic and lower first-four action exploration, no incoming optimizer, identical command and learner settings. Record first done interval and reason, per-lane episode lengths, behavior-likelihood error, source and executable hashes and all failures. Compare against the archived low-balance v4 control. If this does not improve first-episode survival enough to expose longer-horizon learning, investigate before training. A gain does not prove the neural network has learned or that the full mission works.
