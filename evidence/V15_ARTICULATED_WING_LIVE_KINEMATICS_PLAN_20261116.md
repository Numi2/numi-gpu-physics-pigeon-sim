# Articulated-wing live kinematics instrument check

Question: can the device-physics callback read trustworthy accepted-start COM poses and velocities for every new wing segment, a prerequisite for applying flow-dependent loads to the correct moving links? A previous implementation had observed zero distal velocities, while current MetalWorld source appears to materialize them before the callback. This is an exploratory instrument calibration, not a flight or aerodynamic validation.

Use the v3 41-body fixture from numi-lab commit fd7509590 and the already-built matching 48-capacity Metal library/shader. Compile an observer that only copies the borrowed pre-dynamics `currentBodies` into a shared result buffer, never writes a wrench and never changes the physical state. Run three independent matched-state lanes for one 0.0001-second free-motion step in zero gravity, with zero effort, no policy, no aero, no contacts, and identical coordinates except for declared rates: lane 0 all zero; lane 1 only the left elbow at +1 rad/s; lane 2 both elbows/wrists and root translation and rotation at declared nonzero rates. Record exact q/v inputs, all 41 positions, orientations, linear and angular velocities, compiler/binary/shader hashes, commands, and solver diagnostics. Compare each starting state to the independent FP64 `computeArticulatedBodyKinematics` result in matching world/COM coordinates.

Prediction: all lanes dispatch and accept one step; every position, linear and angular velocity component differs from FP64 by at most 1e-5 in SI units and each body orientation differs by at most 1e-5 modulo quaternion sign. Lane 0 is motionless, lane 1 has nonzero left hand velocity while the right wing remains still, and lane 2 has nonzero velocities in both wing chains. Missing observer captures, nonfinite output, or any mismatch fails the instrument. Count lanes as three checks of the implementation, not independent biological experiments. Stop after this batch; retain failures and preregister a revision before a changed run. A pass does not establish aerodynamics, collision clearance, folded anatomy, or flight.
