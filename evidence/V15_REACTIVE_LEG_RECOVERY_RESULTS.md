# Reactive ankle and knee screen: no recovery

Four matched research-only feedback variants used the same fixed-posture control and physically identical shader-bound checkpoints. Each exactly matched the baseline q/v and drive targets until the accepted pitch crossed 0.20 rad; the first altered targets at interval 436 had the expected sign and magnitude (0.001502 rad) on the intended bilateral ankle or knee joints.

| Feedback arm | First tilt >= 0.35 rad | First termination | Longest bilateral opposed-normal proxy |
| --- | ---: | ---: | ---: |
| Fixed -0.75 control | 541 | 625 | 578 |
| Ankle positive | 497 | 579 | 528 |
| Ankle negative | 535 | 621 | 576 |
| Knee positive | 477 | 558 | 506 |
| Knee negative | 539 | 627 | 582 |

All four failed the 750-interval and explicit recovery criteria; none returned from >=0.24 rad to below 0.20 rad for 50 consecutive intervals. The knee-negative two-interval difference is not evidence of successful recovery. Bilateral upward branch impulse was present throughout each first episode; opposing toe-normal is a proxy and was lost before termination. These tests reject the specific isolated delayed corrections, not coordinated, earlier or learned strategies. Their shader sources, physically reached checkpoints, input hashes, full q/v/actions and 16-substep contact traces, including post-termination frames, are archived. This development fixture still uses a reconstructed branch, forced perch phase and scripted carrier.
