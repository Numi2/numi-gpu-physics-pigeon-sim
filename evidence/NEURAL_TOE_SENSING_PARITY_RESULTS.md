# Zero-connected front/rear toe-sensing parity

The experimental host compiled with distinct left/right front/rear digit contact groups and 12 local-force observation components. An initial no-policy probe failed because the visual task requires a native policy; a second probe intentionally bound the old pack and reported the expected changed task and observation contract. Both probes and their logs are archived. The policy was then migrated to the exact new contract by inserting 12 zero-weight input columns at offset 216 before the existing visual suffix, retaining all other actor and critic weights. A 128-row numerical check produced identical actions with arbitrary new inputs.

On consumed development seed 20370127, the first 300 physical steps using the migrated deterministic pack and isolated host were exactly equal to the original long-horizon checkpoint in q, v, accepted actions and all 816 original observation components. All 12 added force channels were nonzero during the run. This establishes a bounded parity and sensor-availability result, not useful toe control, full task equivalence, or biological validity. Next, train only the new actor input columns and verify inherited weights are unchanged; compare physical performance with the archived baseline and prior checkpoint.
