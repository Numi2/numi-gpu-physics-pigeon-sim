# Biased whole-body PPO updates

Four preregistered v3 PPO updates alternated the retained hard and easy development checkpoints. The stochastic starting actor reproduced the fixed -0.75 deterministic actor exactly on 128 probe observations, while preserving the original critic, normalization and action log standard deviations. Per-update checks show that protected actor weights, biases, distributions and optimizer moments remained unchanged. On the observations sampled for each update, RMS changes in permitted whole-body residual outputs were approximately 0.0004 to 0.0023 per update. The first sampled terminations occurred at intervals 86, 120, 85 and 115 respectively; these stochastic training episodes are not deployment qualification.

The archive preserves the source scripts, native run commands, environment and input hashes, per-update reports, all policy packs including deterministic deployments, rollouts and optimizer states. Matched deterministic deployment trials are reported separately. This training is on the reconstructed, relocated branch fixture with a scripted carrier and forced perch mode; it does not establish autonomous landing or reliable balance.
