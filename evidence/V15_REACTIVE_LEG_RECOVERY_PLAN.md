# Extend the accepted-state recovery screen to ankles and knees

The corrected pitch-trigger screen has shown that both hip signs worsen first-episode survival and one wing sign changes the failure by only one interval; the opposite wing arm is still running. The foot remains loaded until near the end, and earlier static ankle-offset screens failed, so any benefit of active ankle or knee movement must be demonstrated rather than assumed.

Before seeing the remaining wing outcome, repeat the exact preregistered 750-interval hard-start screen with four further variants: both ankle targets or both knee targets, each with positive or negative sign. Use the corrected `threatGeometry.z` pitch and `.w` body pitch rate, the same +0.20-rad trigger and sign times clamp(0.30*(pitch-0.20)+0.10*max(rate,0), 0, 0.04) joint-target correction, preserving existing joint limits and all other actuation. Recreate a physically identical shader-bound step-49 checkpoint for every variant, verify nine-field frame parity, then verify the first changed drive target against measured previous pitch, correct joints, sign and bound. Collect all substep contacts, full actions, q/v, first done and resets. Apply the original screen's 750-interval contact and tilt requirements and its explicit return from >=0.24 to <0.20 rad for 50 consecutive intervals; any sensor, parity or target mismatch invalidates the affected arm. Failed trials remain archived. This is privileged research feedback on a scripted-carrier, reconstructed-branch development fixture, not a trained neural controller or an autonomous landing. If any arm advances, separately preregister easy-start, opposite-signed physical perturbation and teacher-off neural-distillation checks.
