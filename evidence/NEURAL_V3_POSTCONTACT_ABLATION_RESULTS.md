# Post-contact neural output ablation and matched long baseline

The v3 policy and post-contact fixed-output controls had byte-identical first 50 state-trace rows on each consumed development start. From interval 51 onward the control substituted constant outputs for the four learned hip/ankle residuals. The same scripted carrier and all other fixture details remained in use. Both controls lost the terminal qualifying hold: seed 20310111 had a 309-interval streak at 38–346 and no done before 400; seed 20310129 had a 326-interval streak at 41–366 and no done before 400. The corresponding live policies held 363 and 360 intervals through interval 400, respectively. This is evidence that changing outputs mattered on these fixtures, not that observation feedback caused the changes or that recovery from perturbations is learned.

The v1 policy was additionally run for the same 1000 intervals as the v3 development comparison. Seed 20310111 matched v3 with a 963-interval qualifying hold and no done. Seed 20310129 failed at interval 370, with a longest qualifying streak of 252 intervals at 41–292; later automatic resets are excluded. V3 held 960 intervals on that start. This development comparison does not establish generalization.
