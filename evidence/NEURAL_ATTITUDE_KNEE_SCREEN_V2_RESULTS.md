# Corrected bounded knee-feedback screen

This corrected 16-lane screen applies the diagnostic privileged pitch and pitch-rate feedback to knee position targets outside the hip/ankle-only branch. It uses the same original reconstructed fixture, direct-contact actor, seed and lane starts as the invalid screen, which had no active knee feedback. Lane zero is an unmodified control. All actor observations were exactly equal for the first 40 intervals in every paired lane and lane zero stayed exactly equal for all 1000; each modified lane first differed at observation index 51. This shows that the corrected intervention affected the rollout, unlike the invalid screen, but does not isolate the magnitude of the actual target displacement.

Across 15 development lanes, knee feedback extended the first episode in three, shortened it in eleven, and one pair had no termination within the 1000-interval horizon. In lane 9, gains -0.12 on pitch error and +0.06 on pitch rate, bounded to +/-0.04 rad, had no termination by 1000 intervals versus termination at 350 in its matched no-feedback control. These are privileged scripted corrections and the screen does not collect strict all-substep support and opposing-toe-contact checks. It is only a candidate for matched physical trials, not a trained neural controller, a qualified hold or an autonomous landing. The invalid run and the corrected run are both archived in full.
