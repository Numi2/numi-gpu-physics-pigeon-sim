# Matched Monte Carlo actor-credit screen

The four-update joint actor still falls on hard seed 20370113; its +0.04-s gain is below the promotion rule. Prior retained first episodes showed that the critic predicted a more negative terminal value than the actual terminal reward, giving a positive terminal GAE despite failure. GAE and Monte Carlo-minus-critic correlated highly, but that alone did not determine whether the state-value baseline was useful. Test the actor-credit signal directly rather than changing learning rate.

Copy the joint 18-action worker and change only the actor's advantage for the first complete episode to full discounted Monte Carlo reward-to-go, normalized by the existing PPO code across that first episode. Compute backward from the terminal reward using gamma 0.999; do not include post-done transitions. Keep the critic's existing GAE-derived return target, learning rate 0.0003, gamma 0.999, lambda 0.995, output gradient mask, clipping, actor and critic initialization, optimizer, trainer, native checkpoint, RNG seeds, horizon and every other setting identical to joint update 01. The actor and critic gradients are clipped separately. This constant batch-centered baseline is not a learned state-dependent critic; the comparison is exploratory and has variance and finite-batch limitations.

Before update, independently compute Monte Carlo values from the retained completed rollout and require the worker's first/last/mean/std credit telemetry to match, native behavior likelihood parity to pass, all protected weights and optimizer moments to remain untouched, and the newly sampled native rollout SHA-256 to equal joint update 01 byte-for-byte. Preserve source, original and new rollout, hashes, metrics, optimizer, action rows and failed checks. Compare resulting actor changes on the same observations and final per-channel KL. Use fresh optimizer and one update, not adaptive learning-rate tuning.

Evaluate both deterministic one-update actors from the identical v3 hard step-49 checkpoint, 300 resumed 20-ms intervals, no teacher or scheduled resets. Compare first termination and bilateral support/opposed toe-normal proxy. Promotion to further development requires the Monte Carlo actor to extend first termination at least 10 intervals over the matched GAE actor while maintaining bilateral upward impulse; otherwise reject it and stop this screen. Only if that condition is met, run the same two actors on the consumed easy step-50 checkpoint for 300 intervals and require no termination and peak tilt <=0.15 rad in the first 250. Same seed/layout and forced phase/scripted carrier as earlier; neither start is unused and no result qualifies autonomous landing, grip robustness or avian realism.
