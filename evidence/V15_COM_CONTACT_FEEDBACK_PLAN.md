# Center-of-mass/contact feedback identification

The used hard-start perch maintained a 0.45006 kg reconstructed mass-weighted COM approximately 0.024 m ahead in world x of the foot/toe vertical-impulse application point. Following the positive hip pulse, this offset grew to approximately 0.152 m before termination while total upward impulse remained. The model source and runtime hash match the archived prototype, model body names match the replay, and recorded model joint metadata match; the contact point is only an impulse-weighted proxy, not a complete wrench center.

Test whether this physical signal can inform a bounded response. In the existing task update kernel, after episode step 3000 and only once five waypoints are flagged, calculate mass-weighted world-x COM and velocity from all v15 bird bodies and the vertical-impulse-weighted x point from the final solver substep's branch contacts. If that contact measurement is invalid, use zero correction. Place the normalized combined error `(COM_x - contact_x - 0.0236) + 0.10 * COM_velocity_x` into the already task-private `airReturnTracking.x` scratch lane only during this late diagnostic phase. The owning source overwrites this lane with mechanical power before reward evaluation; the existing flight use occurs before the tested perch phase. This reuse is an explicitly limited research instrument, not a new production observation contract. Independently reconstruct the first feedback signal from retained accepted body states and the corresponding final-substep contact impulses and compare it with the first changed physical drive target. Verify full observation and q/v parity against the same positive-pulse control before the intervention and inspect all changed target indices.

Repeat the positive hip pulse from shader-bound checkpoints and apply + or - `clamp(0.60 * error, -0.06, +0.06)` radians to both hip drives only after episode step 3010. No body force, contact property or branch geometry may change. Run each for 1000 control intervals with full 16-substep traces. Require a >=0.02-radian induced pitch departure from the unperturbed reference followed by <0.01 radians difference for 50 intervals, no termination, and bilateral upward branch impulse and opposed-toe-normal proxy throughout. Both signs failing is informative, not a reason to claim recovery. Any passing sign also requires opposite pulse, independent starts, ordinary actor observations and neural learning, and autonomous landings; no full folding elbow or wrist exists in v15.
