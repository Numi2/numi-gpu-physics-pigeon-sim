# Matched leg-posture direction screen

The hard reconstructed start crosses its tilt threshold while both feet still carry upward load. Rear-toe closing is already at the established target cap; the negative rear-toe command causes earlier support loss. Constant wing/tail commands and joint-policy learning did not recover the fall. A prior small matched hip pulse on another used start briefly changed body pitch in a measurable direction, but did not demonstrate a recovery law. Test whether a sustained bounded hip or ankle correction can improve the current hard-start equilibrium without changing physical joint or torque limits.

Use the exact v3 evaluation shader, retained step-49 checkpoint, baseline deterministic actor, native executable, seed and 300-step horizon of the previously archived `zero` control. Make four isolated packs which alter only the two bilateral hip residual outputs 0/1 or ankle residual outputs 2/3 by +0.5 or -0.5, preserving all other actor parameters and outputs. Existing task code clamps each residual to [-1,1], scales by 0.08 radians and applies the original per-joint position and effort limits. Collect actual target values and 16-substep contact traces; all modes start from identical physical checkpoint and actor observation, with no teacher or scheduled resets. The other wing, tail, neck and toe controls remain present. These static probes are not a trained or general control law.

Compare against the retained zero-control first episode: absolute first done 257, 208 relative intervals and 156 consecutive bilateral front/rear opposed-normal proxy intervals. A candidate passes this exploratory screen only if first done is at least 10 intervals later and the longest opposed-normal proxy streak is at least 10 intervals longer, with positive bilateral upward impulse throughout. Record any joint-target clipping and all effects, including failures and post-done traces; count only the first episode. If a candidate meets the criterion, preregister and run a matched easy-start control before any learning or promotion. The sample budget is four signed interventions on a consumed seed; no adaptive learning rate, unused layout, autonomous landing, verified grasp, or biological validation is claimed. A poor outcome does not rule out time-varying multi-joint control.
