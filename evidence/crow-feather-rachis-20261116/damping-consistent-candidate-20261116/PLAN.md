# Experimental damping-consistent fixed-support correction

Hypothesis: for the no-CCD world fixed-support experiment, use each rod's predictor decay `d=exp(-c*h)` consistently: an impulse velocity correction changes predictor position by `h*(v_after-v_free)/d`, and the hard-row velocity target requests `v_after = v_free + d*(x_target-x_free)/h`. These are the discrete predictor's kinematics, not a claim that its nonlinear dynamics or damping are physically correct. Test this only as an experimental patch, not a production promotion. The original candidate and failures remain archived.

At unchanged 1 ms, run 100 resident steps for each of damping 0 and 100 on the same 9-node fixed-support fixture. Require every native step to succeed, every support error <=1e-8 m, every support velocity speed <=1e-5 m/s, and every observed-frame total energy <=1.001 times its initial energy. Also record the previously defined damped endpoint free-node y force-balance measurement with its original 0.01 N bound; this is a separate fail gate, not redefined by the kinematic test. Preserve all observations, source patch, hashes, build logs and failures. Run the existing quality and rollback controls; mark any changed premise explicitly. Do not run dynamic targets, CCD, mixed-contact, or flight as if they were qualified by this test.

Stop and keep the patch unpromoted if a result fails, nonfinite values occur, support and velocity cannot both pass, or the native run does not publish every state. No reduction of physical timestep. Further generalized integration requires work-conjugate contact impulses, moving articulated targets, nonlinear force/energy consistency, and mixed contact testing.
