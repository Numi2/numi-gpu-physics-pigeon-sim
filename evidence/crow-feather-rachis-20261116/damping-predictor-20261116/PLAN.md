# Predictor-damping hypothesis for the fixed-support velocity failure

Hypothesis derived from current source: the rod predictor reports `v_free = exp(-c*h) * (x_free - x_old) / h`, while world correction uses `x_new = x_free + h * (v_new - v_free)`. When a node starts exactly at a fixed target and the corrected position returns to that target, these equations predict `v_new = (1 - exp(c*h)) * v_free`. If damping is zero this predicted offset vanishes. The formula is a diagnostic of the split integrator, not a proposed production fix.

Run one free native world step with the same nine-node initial state and no attachments at c=0 and c=100, with the unchanged h=0.001 s, and compare each support node's x/y/z prediction to the previously retained attached step 1. Record source, binary and shader hashes, output, errors and failures. Check the free predictor position/velocity relation within 1e-5 m/s and the predicted attached velocity within 1e-5 m/s, allowing FP32 position error in the retained support state. If either check fails, reject this explanation; if both pass, report evidence consistent with the split mismatch only in these conditions. This does not justify changing timestep, validate constraint impulses or establish dynamic wing/contact correctness.
