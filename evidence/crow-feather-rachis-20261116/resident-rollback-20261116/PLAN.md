# Resident failure and recovery for supported rod

The production resident checkpoint API excludes rod worlds and this solver configuration. Test device-resident rollback without claiming that unsupported API works: run a successful fixed-support step, submit a second step with unchanged 1 ms timestep but quality feasibility tolerance 1e-12, require an actual GPU step rejection, and inspect the returned full published articulated q/v, scene bodies, rod nodes and rod edges against the prior accepted result, bit for bit. Restore the original tolerances, execute one successful continuation and compare its full published physical state to a fresh independent control run of two successful steps from the same initial conditions. Record statuses, exact states or hashes, controls, source/patch identity and all failures. Check the full state vectors, not just rod coordinates. A failure to provoke a GPU error, missing state, acceptance of a failed second step, or a byte mismatch fails/inconclusively ends this test; do not weaken bounds after inspection. Use damping 100, nine-node fixture, no external contact, fixed supports, and the archived damping-consistent research patch. Explicitly record whether diagnostic caches or inactive private buffers are not compared; this is not proof of all topology and contact modes. Keep the experiment unpromoted, and preserve every attempt and output.
