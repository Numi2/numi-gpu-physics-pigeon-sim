# GPU compensated 3D rod stretch-force control

Extend the previous endpoint subtraction control to a physically relevant nonlinear primitive: 3D segment length, extension from rest length, and scalar Hookean rod tension `EA*(length-rest)/rest`. Use 96 deterministic segments, 32 each at common translations x=0, 1 and 16 m, random three-dimensional orientation, lengths in [0.003120, 0.003130] m, rest 0.003125 m and EA=2.129e9*3.449e-6 N. Encode endpoint coordinates and rest length as FP32 high/low pairs. In the M4 Pro native Metal kernel with fast math disabled, use compensated subtraction, squared-length accumulation and one sqrt correction before subtracting the high/low rest length. Compare tension against an independent Python double `math.hypot` reference for the unrounded generated coordinates. In parallel evaluate a naive one-float world-coordinate tension for each case. Require all 96 finite values, maximum compensated tension error <= 0.0001 N, and at least one naive tension error > 0.01 N. Record input source and binary, kernel, native device/compile logs, all outputs and hashes, and any failed results. This is a component experiment only; it does not implement state updates, damping, bending, contact, attachment, rollout performance or a feather model. No timestep change.
