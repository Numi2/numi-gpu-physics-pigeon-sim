# GPU compensated coordinate difference control

Test whether M4 Pro Metal can retain small edge differences from two-FP32 high/low world-coordinate endpoints without collapsing each endpoint to one float. Generate 96 deterministic endpoint pairs with common translations 0, 1 and 16 m and separations in [0.001, 0.01] m using Python `random.Random(204816)`. Encode each original double endpoint as FP32 high plus FP32 residual. Run a native Metal kernel with compiler fast math disabled that computes a compensated endpoint difference as a high/low float pair; compare the reconstructed result against the original Python double difference. Also record the naïve high-only FP32 difference for each case. Require maximum absolute compensated error <= 3e-12 m over all 96 cases and require at least one naive error > 1e-8 m, with all finite outputs and correct case count. Record fixed inputs, source, binary results, compilation mode and identities. This is an elementary representation arithmetic probe, not an implementation of the rod integrator, GPU norm, collision, full force, dynamics, performance or physical feather qualification. It cannot recover information from previously rounded coordinates. No timestep is changed.
