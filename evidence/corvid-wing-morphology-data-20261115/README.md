# Corvid wing-motion source data and reproducible angle extraction

## Northwestern crow dataset

Baliga VB, Szabo I, Altshuler DL. “Range of motion in the avian wing is strongly associated with flight behavior and body mass.” *Science Advances* 5, eaaw6670 (2019), https://doi.org/10.1126/sciadv.aaw6670. Original data and analysis code: https://doi.org/10.6084/m9.figshare.8856161.v3, licensed CC BY 4.0, https://creativecommons.org/licenses/by/4.0/.

`baliga-crow-source/` retains byte-for-byte selected crow landmark files, the relevant author import and angle functions, and specimen metadata from the publisher's range-of-motion ZIP. `baliga-source-extraction.json` records the ZIP's original MD5 and SHA-256 and every extracted file's hash. Source archive MD5 matched Figshare: `de95b4c4fe6a290086aaa0afc37eae10`. The article groups these files under *Corvus caurinus*; one specimen's original filenames use `Cor_bra` while author scripts assign it to `Cor_cau`. We preserve this ambiguity and do not claim unverified specimen identity.

`extract_measured_angles.py` applies the original 3D vertex-angle convention to shoulder–elbow–wrist and elbow–wrist–distal-manus landmarks, retaining source frame numbers and invalid-frame counts. `verify_author_angles.R` executes only the author's actual `xyzangles` function from the archived source (it does not source the package-installing R script) and checks every derived angle against it; maximum absolute discrepancy was below 5.0e-10 degrees across 3,046 valid frames. `measured-angle-manifest.json` identifies inputs, outputs, hashes, ranges and missing frames. These are manual movements of cadaver wings: observed extrema are not independent joint limits, natural motion frequencies or living posture preferences. Their joint pairs constrain a future crow model only after mapping anatomical coordinate frames and resolving specimen identity; no such calibration is claimed here.

## Raven dataset

Harvey C, Wood JCM, Bektas U, et al. “Birds can transition between stable and unstable states via wing morphing.” *Nature* (2022), https://doi.org/10.1038/s41586-022-04477-8. Source collection: https://doi.org/10.6084/m9.figshare.c.5503989. The single common-raven specimen `Cor_cor_20_0908` comes from the authors' CC BY 4.0 input and output collections, https://doi.org/10.6084/m9.figshare.14935659.v2 and https://doi.org/10.6084/m9.figshare.14935662.v2. The original Figshare MD5 values for `raven-transformed.csv`, `raven-inertia-results.csv`, and `allspecimen-birdinfo.csv` are respectively `0a7634654387d63eee405d2e8f1553e1`, `e86a3093f42cb6f131e47be288cabb4c`, and `37aab61a929411b4245dd3cbe68325f7`; each downloaded file matched. Raw column names and values are preserved, including names that suggest units; units and anatomical coordinate conventions must be verified against the source method before numerical use.

The raven file includes 2,110 transformed frames across three hand-manipulated trials, with paired `elbow` and `manus` columns. The species is a related corvid, not an American crow. Neither this dataset nor the crow cadaver data establishes active control, muscle strength, dynamics, contact behavior or autonomous flight/landing.
