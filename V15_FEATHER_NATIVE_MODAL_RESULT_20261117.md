# Native Metal linear modal dynamics control

The preregistered fixed-step GPU control passed on the M4 Pro. Across 80 sequential 0.125 ms steps, the largest node-position error against the independently computed FP64 linear modal reference was 4.998e-10 m (0.000500 micrometres), maximum relative energy deviation was 8.73e-6, and maximum total linear momentum error was 2.32e-12 kg m/s. All states were finite. No timestep reduction was used. The test uses precomputed mass-normalized FP64 eigenmodes uploaded as FP32, and applies exact transitions for the resulting fixed linear system; all source, complete states, inputs, commands, hashes and limits are archived under `evidence/crow-feather-rachis-20261116/native-modal/`.

The two nominal rigid modes had small negative finite-difference eigenvalues and were set to zero as specified. The first non-rigid mode of this short uniform model is about 7.65 kHz, with higher modeled modes up to 90 kHz; these are properties of this surrogate, not measured full-feather biological frequencies. The test is planar, free, linearized and constant-Hessian, and omits nonlinear deformation, attachments, contact, aerodynamic loading and real feather geometry. It is a numerical reference, not a working production feather integrator, benchmark or qualification of the crow.

Sampling limitation: 0.125 ms corresponds to 8 kHz sampling and a 4 kHz Nyquist frequency, below all of this free model's non-rigid frequencies. Exact transition reproduces the isolated linear system at the sampled times but the recorded samples alias the intervening oscillations. This test cannot establish continuous feather motion, visual appearance, or interaction with time-varying aerodynamic loads and collisions between samples.
