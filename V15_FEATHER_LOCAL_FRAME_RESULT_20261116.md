# Free-rod local-frame translation control, 2026-11-16

The bounded prediction in `V15_FEATHER_LOCAL_FRAME_PLAN_20261116.md` passed for this fixture. The opt-in native standalone API shifts each rod's positions by its own first-node origin in double precision before GPU upload, and restores the origin in double precision after a successful solve. Source is on the experimental Numi Lab branch at `e5562e150`; the API is not integrated into MetalWorld.

For identical 9-node, 25 mm free rods at x = 0, +1 and -1 m, the old world-coordinate upload's final total-energy ratios relative to the origin were 1.136831 and 1.018184. Local-frame ratios were 1.000000 for both offsets, with maximum relative-position discrepancies about 0.0000000404 and 0.0000000060 micrometres respectively (the printed data have finite precision). The origin result matched the unmodified path. The attached-rod control returned invalid_configuration before dispatch and left the caller's output unchanged. The separate automated local-frame test and five existing v15/equality-guard tests passed; see `local-frame/ctest-last.log` and raw JSONL for inputs and outputs.

This result addresses only coordinate representation in a standalone free-rod submission. It does not address the observed numerical loss of bending energy, modal phase error, hard attachment solver, moving-body reaction forces, contacts, physical feathers, flight, landing, or balance. It is not a biological validation. The API explicitly rejects attachments, rigid bodies and tool contact; it is experimental and has not been promoted to the shared production branch. No conclusion about performance is made.
