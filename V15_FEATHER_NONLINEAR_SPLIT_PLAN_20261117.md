# Nonlinear force-split research oracle

Test a CPU research-only, symmetric split: exact evolution of the precomputed 27-dimensional linear modes between half-step impulses from the native nonlinear force minus the linearized force. Use the retained 3D moving-point-mass model, matched initial state and the same 0.125 ms interval for 80 steps. Compute native nonlinear forces with the 1e-9 m central energy gradient whose sensitivity was retained separately. Check forward motion, then negate velocities and apply the same 80 steps to test time reversibility. Also run the identical modal code with the nonlinear kicks disabled and compare its sampled states to the prior GPU linear reference.

Preregister: the kicks-disabled path must match the GPU linear reference to <1 micrometre; the nonlinear split must remain finite, native total-energy drift <1%, and return to the initial node positions within 1 micrometre after velocity reversal. Preserve every state, source, commands, hashes, energy and failures. These are necessary controls only: they do not establish trajectory or phase accuracy for the nonlinear dynamics, continuous collisions, articulated rotational coupling, physical feathers, throughput or mission qualification. Do not change timestep or promote to MetalWorld on this result.
