# Independent nonlinear trajectory reference

Use the same native rod energy and 3D moving-point-mass coordinate elimination to construct an independent adaptive high-accuracy DOP853 reference for the first 10 ms of the retained initial-value problem. Evaluate the native energy gradient with the already validated 1e-9 m central difference; sample at the original 80 timestamps. Run two independently tightened error tolerances, retain every sample, and measure their agreement and native energy drift before interpreting comparisons. This adaptive integration is a measurement reference only, not a proposed timestep reduction or a production algorithm.

Preregister: the two references must differ by <0.05 micrometres at every sampled node and each must have <0.1% native total-energy drift; otherwise the comparison is inconclusive. If qualified, predict that the nonlinear split has <1 micrometre maximum position error and at least 20% lower maximum position error than the uncorrected linear GPU trajectory. Record exact tolerances, evaluation counts, native library identity, sources, outputs, failures and timing. A pass would still concern one fixed-twist short-segment point-mass surrogate without contact, aerodynamics, wing articulation or biological validation.
