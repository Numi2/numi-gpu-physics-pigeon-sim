# Native GPU two-way constrained rod reference

Extend the isolated dense native Metal KKT diagnostic to nine planar rod coordinates plus three independent moving point-mass support coordinates. Each equality constrains one rod support node to its corresponding mass; neither side is fixed to the world. Use the same native-energy linearized Hessian, same step and local geometry; give the support masses finite positive mass and run rest/incoming rod and support velocities in both rod-node orders. Compute all 12 coordinates and equal-and-opposite support forces simultaneously. Compare to an independent dense FP64 KKT solve using the same inputs; measure total momentum, accounting for the small nonzero numerical row sums of the finite-difference Hessian when evaluating the discrete balance.

Preregister: all four cases must factor successfully, max dynamic force residual <0.01 N, equality position error <1e-9 m, FP64 position difference <0.05 micrometres, mapped ordering difference <0.05 micrometres, and total linear momentum-balance error <1e-8 kg m/s. Save inputs, outputs, code, binary/shader identities and failures. This is a one-step, one-dimensional translational contact-free surrogate, not a rigid articulated wing joint, physical feather, production solver or a flight qualification.
