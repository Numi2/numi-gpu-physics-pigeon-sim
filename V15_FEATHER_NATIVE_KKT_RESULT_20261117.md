# Native Metal constrained KKT prototype

The preregistered one-step planar control passed on the Mac mini's Apple M4 Pro GPU. Four FP32 cases—rest and nonzero incoming velocities, each in forward and reversed node order—completed with positive-definite factorization. Against the independently evaluated double-precision model, maximum dynamic-force residual was 2.54e-5 N, maximum hard-support position error 3.71e-11 m, maximum difference from the FP64 KKT position 7.62e-11 m, and maximum mapped node-order difference 3.82e-11 m. The validation script enforces the original thresholds. Source, input and output bytes, device report, compilation options, build/run commands and binary/shader hashes are retained under `evidence/crow-feather-rachis-20261116/native-kkt/`.

This is a standalone diagnostic kernel, not the MetalWorld solver or a production change. It uses a precomputed linearized Hessian for a planar nine-node rod, fixed supports and a dense solve; it does not simulate nonlinear 3D feather mechanics, mixed contacts, moving articulated wings, aerodynamic loading, oscillation fidelity or a complete flight. No throughput or real-time claim is made. The existing fail-closed MetalWorld equality guard was not bypassed or changed for this experiment.
