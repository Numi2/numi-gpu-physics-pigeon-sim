# Native rod translation-invariance control

The native bending-gradient finite difference scales each coordinate perturbation with the absolute world coordinate as well as segment length. Test whether this violates translational invariance at bird-scene scales. Independently initialize the same nine-node pre-shaped undamped rod at x offsets 0, +1 and -1 m; all velocities and physical material parameters match. Run one native CPU and one native Metal standalone step at the previously used 0.125 ms. Remove the initial rigid translation from every final state. Predict all backends return success, positions for each offset match the zero-offset case within 2 µm and total energies within 1% of the corresponding zero-offset energy. Record original states, velocity, twist, energy, offset, statuses and hashes. The relaxed 2 µm/1% thresholds admit float32 coordinate precision but are far below a bird-scale displacement. A failure reveals a tested numerical invariance problem; a pass does not establish physical dynamics or coupling.
