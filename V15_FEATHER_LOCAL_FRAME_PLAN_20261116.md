# Opt-in local-frame free-rod prototype

Introduce an explicit standalone Metal rod option that subtracts the first input node's double-precision position before float conversion and adds the same origin to published double positions. Restrict it to free rods with no attachments, rigid bodies or tool collision; reject unsupported combinations rather than transforming them partially. Velocities, gravity and relative self-contact are translation invariant. The default remains disabled. This is a standalone upload/publication path, not a MetalWorld or wing attachment solution.

Before execution, compare the same independent zero, +1 m and -1 m states in one batched GPU run with the option off versus on. Predict on-mode relative final positions agree within 0.1 µm and energies within 0.1% across translations, with the zero-offset on/off outputs within 0.1 µm. Require a deliberately attached rod to be rejected before dispatch and all original off-mode behaviors unchanged. Record every state, flags, diagnostic, input hashes and timing; any failure or unsupported case is retained. This addresses coordinate representation only and does not qualify energy dissipation, moving attachments, contact, feathers or flight.
