# Midpoint phase accuracy against a linearized native-energy solution

Energy conservation does not establish the timing of oscillation. Linearize the native rod potential around the straight rest state using a central FP64 Hessian, mass-weight it using the recorded nodal masses, and propagate the small initial deflection with an independent eigendecomposition and exact linear oscillation formula. Compare all nine transverse node positions at each of the eight existing 0.125 ms midpoint output times. Predict maximum absolute position discrepancy below 1 µm (4% of initial maximum displacement). Report mode frequencies and displacement differences at every step. Validate Hessian symmetry, nonnegative modes to numerical tolerance, and initial reconstruction; declare inconclusive if these checks fail. The linearization does not validate a nonlinear 3D feather, and differences can include small nonlinear effects as well as discretization phase error. No new trajectory is fabricated.
