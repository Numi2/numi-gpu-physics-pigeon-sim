# Preregistered fixed-support tolerance sensitivity

Use the same nine-node, pre-shaped +25 um carrion-crow surrogate and three stationary hard attachments from the failed fixed-support experiment. Independently run one CPU DER step from the identical zero-velocity initial state at each of three positional correction tolerances: 1e-8, 1e-10, 1e-12 m; keep the 4096-sweep ceiling, 1 ms timestep, 100/s damping, material, geometry and all other parameters fixed. Save all node and twist states, status/iteration counts, full model energies, attachment reactions and input identities. Compute final node elastic forces with centered 1 nm differences of the actual published complete state. If the solve rejects, retain the status and do not treat the original initial state as a successful output.

Predict stricter tolerances reduce both the maximum unconstrained-node force and midpoint reaction error monotonically. Predict the strictest arm is accepted, has maximum unconstrained-node force below 0.01 N, midpoint reaction magnitude within 15% of 0.64749 N, and total energy no greater than its initial value plus 1e-10 J. A failure rejects the simple tolerance explanation; it does not by itself locate the cause. Three arms, one step each, no retries. This constrained laboratory surrogate is not a physical-feather, flight or biological qualification.
