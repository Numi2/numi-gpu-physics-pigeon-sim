# Crow neural branch-balance evidence

This orphan evidence branch records subsequent experiments for the v15 simulated American crow. Earlier checkpoint reconstruction, all v1/v2 rollouts, failures, source and the five-angle video are preserved in [the NumiLab evidence branch](https://github.com/Numi2/numi-lab/tree/fd2739e81654bb72c09d4f9eeecc9d2e7e068907/artifacts/crow-v15-recorded-restart-20261114), through commit `fd2739e81654bb72c09d4f9eeecc9d2e7e068907`. This split avoids further growing that near-quota repository.

All experiments use a reconstructed forced-landing development fixture with a relocated round branch and a scripted terminal carrier, not a continuous autonomous mission. Results, failed trials and simulator auto-resets are retained and distinguished from success; no biological validation is implied. The first v3 launch was rejected by the optimizer configuration guard, as documented in the amendment and earlier archive.
