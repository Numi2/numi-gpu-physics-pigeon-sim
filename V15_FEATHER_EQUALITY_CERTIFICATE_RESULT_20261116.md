# Quality solver reports success despite equality error

The start-state candidate was re-run with the original one-step supported rod fixture and full quality status. With 100/s damping, status code 0 was returned while the equality certificate was 0.0003257623 m/s, exactly the magnitude of the independently observed midpoint velocity. This is 16.29 times the configured feasibility tolerance 0.000020 m/s. Without damping the equality certificate was 0.0003599280 m/s and also matched measured midpoint velocity. The source convergence check uses optimality and cone/scalar feasibility, not the separately stored equality certificate; the effective compliance floor reported was 0.589883 in both cases. This identifies a specific acceptance gap for the tested equality-constrained, small-rod fixture, not a completed solver repair. Source, patch identity, hashes, statuses and states are archived.
