# Alternating sweep candidate for fixed-support rod

The retained node-order experiment found a 0.3187 micrometre mapped difference and strong reaction asymmetry. Test a research-only candidate that alternates forward and reverse short-rod stretch/bend/twist constraint sweep directions on successive existing iterations, without changing the timestep, tolerance, iteration cap, damping, model or support conditions. This tests whether deterministic sweep direction is a major cause; it is not an endorsement of order selection or a general hard-constraint solution. Apply it atop the archived nine-row fixed-world Schur prototype, with the committed equality gate bypassed only inside the rejected diagnostic as in previous tests.

Before running, require both node orders to complete, max mapped displacement difference <0.05 micrometres, each max free-node force <0.01 N, endpoint force difference <0.01 N and midpoint force within 5% of 0.62905 N. Preserve full source patch, native binary/shader identities, states, constraints and failures. If any criterion fails, retain the result without promoting this candidate.
